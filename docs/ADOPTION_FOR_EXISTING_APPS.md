# Adoption For Existing Apps

1. Install packed or published `@coderlife/ui-core` and `@coderlife/ui-components`.
2. Keep existing `ThemeProvider` and MUI theme augmentation modules.
3. Introduce `DataTable`, `TreeExplorer`, and `DashboardLayout` in one route/feature at a time.
4. Enable analytics runtime only after consent flow is wired.
